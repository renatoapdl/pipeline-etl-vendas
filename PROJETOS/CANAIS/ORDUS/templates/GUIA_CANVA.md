## 🛠️ Passo a Passo para Criar no Canva

### 1. Criar Conta no Canva
1. Acesse canva.com
2. Crie uma conta gratuita
3. Verifique seu email

### 2. Criar os Templates

**Para cada template (Reel Manhã, Reel Noite, Carrossel):**

1. Clique em "Criar design"
2. Selecione as dimensões personalizadas:
   - Reels: 1080 x 1920 px
   - Carrossel: 1080 x 1080 px

3. Siga as especificações acima para cada slide

### 3. Usar Bulk Create (para gerar em lote)

1. Crie o template com campos de dados
2. Vá em "Apps" → "Bulk Create"
3. Importe o CSV (`content/planilha_conteudo.csv`)
4. Mapeie os campos do CSV para os elementos do design
5. Clique em "Gerar 21 designs"

### 4. Exportar os Designs

1. Selecione todos os designs gerados
2. Clique em "Compartilhar" → "Baixar"
3. Formato: PNG ou JPG
4. Qualidade: Máxima
5. Salve na pasta `images/`

## 📝 Dicas de Design

### Hierarquia Visual
1. **Título** → Maior e mais destacado
2. **Versículo/Salmo** → Médio, com cor de destaque
3. **Corpo do texto** → Menor, legível
4. **CTA** → Pequeno, mas visível

### Contraste
- Sempre use cores claras em fundos escuros
- Evite textos em cores muito próximas ao fundo
- Teste a legibilidade em telas pequenas

### Espaçamento
- Mantenha margens de pelo menos 50px
- Não coloque texto muito próximo às bordas
- Use espaçamento entre linhas de 1.5

### Consistência
- Use as mesmas cores em todos os templates
- Mantenha as mesmas fontes
- Padronize o posicionamento dos elementos
