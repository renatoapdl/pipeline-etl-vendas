# 📚 Guia Passo a Passo para Criar Templates no Canva

## 🎯 Objetivo
Criar 3 templates no Canva para gerar 21 posts automaticamente usando Bulk Create.

---

## 📋 Pré-requisitos
- Conta no Canva (gratuita)
- Arquivo CSV: `content/planilha_conteudo.csv`

## 🌅 TEMPLATE 1: REEL MANHÃ (1080 x 1920 px)

### Passo 1: Criar Design
1. Acesse [canva.com](https://canva.com)
2. Clique em **"Criar design"**
3. Selecione **"Dimensão personalizada"**
4. Digite: **1080 x 1920 px**
5. Clique em **"Novo design"**

### Passo 2: Criar Slide 1 (Capa)
1. **Fundo:** Adicione um retângulo com gradiente:
   - Cor 1: `#0D1B2A` (azul escuro)
   - Cor 2: `#1B2838` (azul médio)
   - Direção: Diagonal (135°)

2. **Texto Principal:**
   - Adicione texto: "Bom dia, filho de Deus"
   - Fonte: **Playfair Display**
   - Tamanho: **72px**
   - Estilo: **Bold**
   - Cor: **Branco (#FFFFFF)**
   - Posição: **40% do topo**

3. **Subtítulo:**
   - Adicione texto: "Oração do Despertar"
   - Fonte: **Montserrat**
   - Tamanho: **36px**
   - Cor: **Dourado (#D4AF37)**
   - Posição: Abaixo do título

4. **Elementos Decorativos:**
   - Adicione estrelas ou pontos dourados sutis
   - Use ícones do Canva ou desenhe círculos pequenos

### Passo 3: Criar Slide 2 (Versículo)

2. **Ícone:**

   - Fonte: **Playfair Display**

## 🔄 USAR BULK CREATE (Gerar 21 Posts)

### Passo 1: Preparar CSV
1. Verifique se o arquivo `content/planilha_conteudo.csv` está correto
2. Abra o CSV no Excel/Google Sheets para conferir

### Passo 2: Abrir Bulk Create
1. Abra o template desejado no Canva
2. Vá em **"Apps"** → **"Bulk Create"**
3. Clique em **"Importar dados"**

### Passo 3: Importar CSV
1. Selecione o arquivo `content/planilha_conteudo.csv`
2. O Canva vai detectar as colunas automaticamente
3. Verifique se todos os dados foram importados

### Passo 4: Mapear Campos
1. Clique em **"Connect data"**
2. Mapeie cada campo do CSV para o elemento do design:
   - `manha_versiculo` → Texto do versículo (Slide 2)
   - `manha_oracao` → Texto da oração (Slide 3)
   - `manha_reflexao` → Texto da reflexão (Slide 4)
   - `manha_oracao_conclusiva` → Oração conclusiva (Slide 5)
   - etc.

### Passo 5: Gerar Designs
1. Clique em **"Gerar 21 designs"**
2. Aguarde o Canva criar todas as variações
3. Revise os designs gerados

### Passo 6: Exportar
1. Selecione todos os designs
2. Clique em **"Compartilhar"** → **"Baixar"**
3. Formato: **PNG** ou **JPG**
4. Qualidade: **Máxima**
5. Salve na pasta `images/`

## 🎨 Dicas de Design

### Hierarquia Visual
1. **Título** → Maior e mais destacado
2. **Versículo/Salmo** → Médio, com cor de destaque
3. **Corpo do texto** → Menor, legível
4. **CTA** → Pequeno, mas visível

### Contraste
- Sempre use cores claras em fundos escuros
- Evite textos em cores muito próximas ao fundo
- Teste a legibilidade em telas pequenas

### Espaçamento
- Mantenha margens de pelo menos 50px
- Não coloque texto muito próximo às bordas
- Use espaçamento entre linhas de 1.5

### Consistência
- Use as mesmas cores em todos os templates
- Mantenha as mesmas fontes
- Padronize o posicionamento dos elementos
