## PROJETOS RELEVANTES

### pipeline-etl-vendas — Pipeline ETL em PySpark
**Stack:** Python, PySpark, Parquet
- Pipeline ETL de vendas: extração de CSV, validação e limpeza de dados (27 → 25 → 23 registros válidos)
- Carga em camadas **bruto/tratado** em Parquet e sumarizações (faturamento, ticket médio)
- Inclui **9 testes automatizados** e documentação completa de arquitetura
- [github.com/renatoapdl/pipeline-etl-vendas](https://github.com/renatoapdl/pipeline-etl-vendas)

### case-tratamento-input — Qualidade de Dados (Databricks SQL)
**Stack:** Databricks SQL, Data Quality
- Case com **13 regras de negócio em uma única consulta** (bronze ao ouro) sobre 40 registros sujos
- Sentinelas: CEP `00000-000`, CPF `000.000.000-00`, datas `1900-00-00` (decisão de tipo documentada)
- Normalização de telefone `(XX) AAAA-BBBB`, país `Brasil` canônico (mapa de typos), estado com coluna de nome completo (27 UFs + NULL)
- **Auditoria coluna a coluna** via derived table (19 `InvalidState` e 18 `InvalidCountry`)
- [github.com/renatoapdl/case-tratamento-input](https://github.com/renatoapdl/case-tratamento-input)

### clima-eusebio — Dados em Tempo Real
**Stack:** Python, API wttr.in
- Aplicação desktop que consome API REST, processa dados JSON e atualiza informações a cada 5 minutos
- Demonstra consumo de APIs e manipulação de dados em tempo real
- [github.com/renatoapdl/clima-eusebio](https://github.com/renatoapdl/clima-eusebio)

### fgo-data-update — Automação de Dados NASA
**Stack:** Python, Automação de Dados
- Automação da atualização de dados de discos VLBI do Rádio Observatório Espacial do Nordeste
- Integração de coleta de dados a processos críticos de radioastronomia
