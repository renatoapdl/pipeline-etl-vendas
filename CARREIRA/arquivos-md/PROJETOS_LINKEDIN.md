Competências: Python · PySpark · Apache Spark · ETL · SQL · Apache Parquet · Data Validation · Pytest · Git · GitHub

Competências: Azure Databricks · Apache Spark · Spark SQL · SQL · Data Quality · Data Validation · Data Cleansing · ETL · Data Engineering
